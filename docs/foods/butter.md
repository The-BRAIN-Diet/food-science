## Overview

Butter is a saturated-fat-rich dairy fat used in small amounts for flavour. The representative composition table includes **vitamin A**, and food-composition analyses also report menaquinones in butter [1]. It is energy-dense, so portions stay small.

Within a BRAIN-aligned pattern it is a culinary fat, not a staple.

## Food Context

### Sourcing

- Use ordinary butter in culinary amounts; it is a flavour fat, not a staple oil.
- See [Grass-Fed Butter](./grass-fed-butter.md) for pasture-fed composition and how it differs from conventional butter.

### Preparation

- Use small amounts for cooking, baking, or finishing.
- It carries fat-soluble vitamins in a dairy-fat matrix; it is not a vitamin supplement.
