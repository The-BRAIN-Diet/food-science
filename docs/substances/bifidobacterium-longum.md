## Overview

This species page provides documentation for separately registered strain identities. Taxonomic membership does not transfer intervention evidence between strains or establish dietary efficacy.

Taxonomic reference: [NCBI NCC2705 record](https://www.ncbi.nlm.nih.gov/Taxonomy/Browser/wwwtax.cgi?id=206672), which places NCC2705 within Bifidobacterium longum.

## Bifidobacterium longum NCC2705 {#ncc2705}

Strain-specific mouse evidence preserved mucus growth, not penetrability or thickness; no fermented-food equivalence or human benefit is established. [Original study](/docs/papers/BRAIN-Diet-References#schroeder_bifidobacteria_2018).
