## Overview

This class comprises histidine, isoleucine, leucine, lysine, methionine, phenylalanine, threonine, tryptophan and valine [1]. Tyrosine is not a member. The class resolves the already accepted indispensable-amino-acid supply record; it does not create nine independent PM admissions.

## Dietary Context

Digestible dietary proteins contribute the constituent amino acids. Presence of all nine is distinct from their amounts, digestibility or adequacy relative to a person’s needs. The class is not assigned an amount from total protein, and every meal need not contain the complete set [1].
