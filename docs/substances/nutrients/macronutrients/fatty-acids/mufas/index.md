Monounsaturated fatty acids (MUFAs) are a **class** of fatty acids with one double bond. **Oleic acid** (18:1 n-9) is the main dietary MUFA. It is not the same as the MUFA class (which also includes palmitoleic acid and others) and it is not the same as “omega-9,” which names a family of n-9 fatty acids rather than a single molecule.
