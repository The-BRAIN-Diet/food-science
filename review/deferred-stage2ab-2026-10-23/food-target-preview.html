BRS2-FM1-PM4 — Glycine

  • Six atoms

    Input = Glycine

    Input type = substrate

    Biological role = Glycine is the acceptor substrate of glycine N-methyltransferase, which consumes SAM and forms SAH and sarcosine during methyl-group handling.

    Evidence source = {"finding_ids":["PM4-F7"],"citation_keys":["pakhomova_gnmt_structures_2004","luka_gnmt_knockout_2006"]}

    Limitation = Endogenous glycine synthesis and other methyltransferases also contribute. Enzyme loss is not glycine deficiency; extra dietary glycine has not been established to normalise whole-cycle or brain methylation.

    Dietary input = Yes

BRS5-FM1-PM1 — Glutamine

  • Six atoms

    Input = Glutamine

    Input type = substrate

    Biological role = Enterocyte metabolic substrate supporting epithelial proliferation, repair, and tight-junction protein maintenance.

    Evidence source = {"finding_ids":["PM1-F6"],"citation_keys":["rao_role_2012","abbasi_systematic_2024","zhou_glutamine_piibs_2019"]}

    Limitation = Glutamine is supplied substantially from endogenous and systemic pools and becomes conditionally indispensable under stress; adult supplementation trials show no overall permeability benefit, so dietary protein or glutamine provision is not established as a general PM1 lever. A separate postinfectious IBS trial supports a selected supplementation response; this does not establish general need.

    Dietary input = Yes

BRS5-FM2-PM4 — Inulin

  • Six atoms

    Input = Inulin

    Input type = substrate

    Biological role = Inulin supplies beta-(2,1)-linked fructan substrate to microbes with the corresponding utilisation machinery, supporting this glycan-processing capacity.

    Evidence source = {"finding_ids":["PM4-F4"],"citation_keys":["sonnenburg_fructan_specificity_2010","long_chain_inulin_elderly_2020"]}

    Limitation = Utilisation genes, chain length, alternative substrates and resident organisms constrain the response. A supplied inulin substrate is not an indispensable intake, a guaranteed abundance shift, butyrate yield, mucus effect or clinical benefit.

    Dietary input = Yes

BRS5-FM3-PM7 — Linoleic acid

  • Six atoms

    Input = Linoleic acid

    Input type = regulatory modulator

    Biological role = Linoleic acid engages intestinal fatty-acid sensing and vagal/brainstem nutrient signalling in the tested mouse circuits.

    Evidence source = {"finding_ids":["PM7-F3"],"citation_keys":["li_gut_brain_fat_2022"]}

    Limitation = This is physiological nutrient sensing, not a beneficial direction or a need to increase linoleic acid. Human food-level circuit responses, vagal tone, ADHD and clinical benefits were not established. Foods generally supply esterified fatty acids released during digestion; the experimental free-fatty-acid stimulus is not a demonstrated food effect. More signalling is not automatically better.

    Dietary input = Yes
