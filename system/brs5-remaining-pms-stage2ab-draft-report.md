## Contract conflicts and interpretation

The KC review contract §2 still says: “Until `individual_key_constraints` is declared, the page is one iKC whose `ikc_id` equals `kc_id`.” The current Stage 2B canonical iKC definition requires an individually registered KC constituent linked to a verified canonical substance ID. BRS5 KC1 retains legacy group-style membership records. The draft therefore uses only the currently supported pool-level representation and separately records constituent identity/migration flags. It does not invent constituent IDs, migrate KC pages or treat missing registrations as scientific exclusion.

Stage 2B principal-selection wording says “Qualification alone, or missing admitted competitors, does not establish primacy.” The user’s subsequent instruction selects the strongest implemented lever set for this testing pass. Dietary Requirements is therefore provisionally promoted to visible §1.1 using its specific experimental relevance and directness. The public qualification remains Diet-Supported; no superiority over unassessed §3.2/§3.3 or clinical efficacy is inferred. Canonical section identifiers remain 3.1/3.1.1–3.1.3.

A concise Supported upstream supply pool summary is not presented as a further independently measured constraint. Individual substrate disclosures are not copied into its summary. Conditional constraint requires context-specific limitation evidence; no blanket inadequacy threshold or transitive KC inheritance is added.
