# Single-PM Functional Mechanisms

A single-PM FM must not manufacture multi-PM integration, broader coverage or confidence uplift. Preserve the existing single-PM phenome alignment rule in `phenome-relationship-schema.md`; this presentation change does not re-adjudicate ratings.

Follow `functional-mechanism-schema.md`: link the child and existing KCs above section 1, then use §4.1 Functional Rationale → §4.2 Evidence Summary → §4.3 Suboptimal Function. Summarise the child’s reviewed evidence and explain the bounded capacity it supports. Do not repeat the child’s mechanism description or copy its evidence dropdowns. Cross-system implications require independently supported evidence.

Canonical example: BRS1-FM3, Phospholipid-mediated DHA Delivery and Membrane Integration. Its evidence supports measured incorporation and delivery-form relevance, not comprehensive membrane coverage or an optimal oral dose.
